# Customer Churn Prediction 📊

## 📌 Overview
This project focuses on analyzing customer data and predicting customer churn using Machine Learning techniques.

The goal is to understand the factors that influence customer churn and build models that can predict whether a customer is likely to leave the service.

## 📂 Dataset
The dataset contains customer information such as:

- Customer ID
- Tenure
- Phone Service
- Contract
- Paperless Billing
- Payment Method
- Monthly Charges
- Total Charges
- Churn

## 🎯 Target
The target variable is:

**Churn**

- `Yes` → Customer left the service
- `No` → Customer stayed

## 🔍 Project Steps

1. Load the dataset
2. Explore and understand the data
3. Perform data cleaning and preprocessing
4. Exploratory Data Analysis (EDA)
5. Data visualization
6. Feature Engineering
7. Train Machine Learning models
8. Evaluate and compare the models

## 🤖 Machine Learning Models

The project applies and compares different Machine Learning models, including:

- Decision Tree
- Bagging
- Boosting

## 📈 Evaluation

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
